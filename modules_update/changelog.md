# 更新日志

## v1.8.6（186）

- 运行环境新增可折叠的 Scene 核心分配检测，分别显示应用与游戏开关；未安装 Scene 时自动隐藏，检测到任一核心分配开启时会在应用页提示环境异常，并可在详情中直接关闭冲突开关。
- 完善子进程线程规则兼容：App 与 Rust 可直接读写 `process(MSF, 0-3) { thread(Thread_*, 0-7) }` 嵌套函数语法，线程规则优先于外层进程兜底；新增线程规则可从历史候选跨进程多选并批量写入，同时兼容 Chromium 多段冒号子进程名称和 Linux 截断线程名。
- 重构绑定规则列表：子进程线程收纳到可展开的子进程父项，整行点击不再误入编辑；删除改为左滑后点击删除图标，并保留二次确认，列表只通过独立编辑按钮修改规则。
- 重构 FPS eBPF 兼容链：按 `RingBuf → StatsMap → PerfEvent` 选择内核可用后端，补充 Android 17 `queueBuffer` 符号、多进程/TID 增量挂载、PID 热重启重锁和稳定帧流筛选；空闲应用无帧时保留 eBPF 主路径并退避重试，明确失败时仍可降级 SurfaceFlinger。
- 完善模块更新会话：下载、管理器检测和安装交接状态可跨 Activity 重建恢复，模块 ZIP 在刷入前校验结构、版本与 ABI；诊断包改为一次 Root 批量采集并限制日志和历史残留大小，避免导出期间频繁拉起 root 进程或占用过多内存。
- 修复子进程子线程规则健康误判：只有完整扫描确认对应子进程实际出现后，才允许其子线程规则累计未命中；子进程没有启动时保持待确认，不再错误显示“可能无效”。
- 完善首次使用引导与规则编辑状态恢复：Root 尚未授权时先停留在前置检查，已有待校准应用时不再要求重复添加；旋转、横屏和平板重建后继续恢复当前步骤、规则草稿、筛选和展开状态。
- 恢复小米 Joyose 冲突处理并保留用户原始状态：仅在 MIUI 环境读取 `SmartOpService` 的真实组件状态，原本已禁用时不做修改；由 AppOpt 禁用的组件会在卸载时精确恢复为原来的 `default` 或 `enabled`，模块升级也会继承恢复责任。
